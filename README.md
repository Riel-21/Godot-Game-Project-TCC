# (The Conquered Crown)

The Conquered Crown is about climbing up a castle that has been conquered by a Snake and it's army.

---

## How to Play
You try to go up the platform levels in the castle to reach minibosses and finaly the boss. 
Facing and killing enemy snakes on the way up to get points (later on: currency).

### Controls
* `W,A,D` / `Arrow keys`: Move Charater
* `KEY_F`: Toggle Attack Mode
* `Q_KEY` / `L_Mouse Button`: Attack
* `R_Mouse Button`: Shoot Player Bullet
