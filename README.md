# (The Conquered Crown)

The Conquered Crown is about climbing up a castle that was taken over by an evil snake and it's army and defeating them to retrieve it back for the kingdom. 

---

## How to Play
The player gets a tutorial at the start for basic contorls and combat.
You try to go up the platform levels in the castle to reach minibosses and finaly the boss. 
Facing and killing enemy snakes on the way up to get points.


### Controls
* `W,A,D` / `Arrow keys`: Move Charater
* `Space Bar`: Jump 
* `KEY_F`: Toggle Attack Mode
* `Q_KEY` / `L_Mouse Button`: Attack
* `R_Mouse Button`: Shoot Player Bullet
